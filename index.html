Open Agent Hackathon 2026 · Track 02 · haqi

A kid asks "can I play outside?"
The answer must come with reasons.

haqi investigates live air data across scattered sources and answers with a one-glance verdict plus the weighted evidence chain behind it — every receipt logged.

API haqi-api.onrender.com/proof Frontend haqi-one.vercel.app Repo TheRealNajim/haqi

The problem

Dashboards answer PM2.5.
Kids ask about football at 4.

  • A 14-year-old with asthma in Lagos doesn't read a map overlay — he asks a question about his own plan.
  • The data he needs is scattered: ground stations, WAQI, forecasts, satellite fire hotspots, structured sponsor views — each with different delays, units, and gaps.
  • Half-missing evidence should never be shown as a clean answer. "Probably fine" is how kids end up indoors with wheeze.

The product

One question in. Verdict + why out.

POST /ask  {"question":"can I cycle in 2 hours","lat":6.5244,"lon":3.3792,"profile":"asthma"}
good to go careful — limit hard running stay in today
  • Every verdict ships with an evidence chain — which station said what, when, how much we trust it, and what was blind.
  • Every /ask writes an append-only trust ledger receipt; /why/{id} renders it as a graph the frontend shows ask-first.

The agent loop

Six steps, and the safety call is never the LLM's.

1 · ParseNVIDIA Nemotron reads kid language; regex-provable time facts always override the model's guess (horizon honesty)
2 · Investigateone adapter per source, in parallel; sponsor SQL view joins the loop like any other source
3 · Weighunit-group consensus — µg/m³ and AQI never blend; stale rows down-weighted and disclosed, never able to produce green alone
4 · Decidedeterministic thresholds + lungs profile; zero LLM in verdict text
5 · Proveappend-only ledger; /why/{id} = receipt graph
6 · NarrateMeterless Nightshift reads only the ledger and writes the kid-paragraph — it may add zero facts

Sponsor stack

Right model. Right lane. Same failure contract.

Zetaris Lightningrecipe view haqi_views.air_quality_readings in the same investigate() fan-out as every other source; malformed rows are quarantined visibly, never silently dropped (live in the deployed API — tested)
Meterless Nightshiftthe narration lane: OpenAI-compatible host on the infra PC; grounded strictly on the ledger; ships degraded to the plain graph if the lane is off
NVIDIA Nemotronparse lane nemotron-3.5-bolt-e4b, ~1.6 s answers on the hosted API — live; verified against /v1/models

Why you can trust the output

We tried to break it. The failures say no.

"football at 9 pm" (beyond the 3 h forecast horizon)verdict: "come back nearer the time" — never a fabricated forecast
Kill the tunnel mid-demoslot returns honest blind rows; verdict degrades, never errors (live-verified)
Feed wrong-ordered SQL rows to the mapperquarantined at weight 0 — visible, blended never
Impossible hour ("at 27 o'clock")no inferable time; falls to the 2 h now-window
Nemotron freed to breeze about the timedeterministic floor beats it; an evening clock bug was caught and made clock-proof
